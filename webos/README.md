# NX Torrent Player — LG webOS TV Client

Клиент **NX Torrent Player** для телевизоров LG Smart TV под управлением **LG webOS** (версии webOS 3.0, 3.5, 4.0, 4.5, 5.0, 6.0, 22, 23, 24+).

---

## ✨ Возможности

- **Для всех телевизоров LG**:
  - Работает на **любых** телевизорах (включая модели **без Root**) через режим разработчика (*Developer Mode*) или *Homebrew Channel*.
- **Управление**:
  - Полная поддержка **LG Magic Remote**: свободное перемещение курсора-указки, клики, колесико для горизонтального скролла лент.
  - Поддержка **D-pad** (стрелок на обычном пульте): встроенный движок пространственной навигации (Spatial Navigation).
- **Воспроизведение**:
  - Потоковое воспроизведение через **TorrServer** (на ПК, сервере, ТВ-приставке или роутере в локальной сети).
  - Аппаратное декодирование через встроенный видеочипсет телевизора (HTML5 `<video>`).
  - OSD-панель управления в стиле Lampa / Horizon: шкала времени, переключение серий, соотношение сторон, текущее время и время окончания фильма.
- **Облачная синхронизация**:
  - Синхронизация закладок (`library.json`) и истории (`history.json`) через **Google Drive** и **WebDAV** (Яндекс Диск, Mail.ru, Nextcloud), полностью совместимая с версиями для Switch и Android.

## 🖥️ Тестирование в браузере на ПК

Вы можете запустить и протестировать webOS-клиент прямо в браузере:

```bash
# В корне проекта или папке webos:
npx serve -l 3000 webos
```

Откройте в браузере: `http://localhost:3000`.
- Клавиши стрелок (Вверх, Вниз, Влево, Вправо), `Enter` и `Esc`/`Backspace` работают как кнопки пульта ДУ.
- Мышь работает как указка LG Magic Remote.

## 📦 Сборка пакета `.ipk`

Для создания установочного пакета используется утилита `ares-package` из состава официального webOS CLI:

```bash
# Установка webOS CLI (если не установлен):
npm install -g @webos-tools/cli

# Сборка .ipk пакета:
ares-package webos/ -o webos/dist/
```

В результате в папке `webos/dist/` будет создан файл:
`org.nxtorrent.player_1.0.0_all.ipk`

## 📺 Установка на телевизор LG

### Вариант 1: Через WebOS Dev Manager (для всех ТВ, без Root)
1. Установите на телевизор официальное приложение **Developer Mode** из LG Content Store и войдите со своей учетной записью LG.
2. Включите в приложении режим *Dev Mode* и *Key Server*.
3. Скачайте на компьютер программу [**webOS Dev Manager**](https://github.com/webosbrew/dev-manager-desktop) (Windows / macOS / Linux).
4. Подключитесь к телевизору по IP-адресу и коду с экрана.
5. Нажмите кнопку **«Install Package»** и выберите собранный `org.nxtorrent.player_1.0.0_all.ipk`.

### Вариант 2: Через Homebrew Channel (для ТВ с Root)
1. Скопируйте файл `.ipk` на флешку или передайте по SFTP на телевизор.
2. Откройте приложение **Homebrew Channel** на телевизоре и выберите установку локального пакета.

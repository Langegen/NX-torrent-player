# Онлайн-просмотр без торрентов в NX Torrent Player

NX Torrent Player поддерживает два способа онлайн-просмотра (без скачивания торрентов):

1. **Совместимость с Lampa / Lampac / BWA** (`https://app.bwa.ad/online.js`, свой сервер Lampac и совместимые зеркала).
2. **Собственный открытый формат `NX Online Plugin v1`** (лёгкий HTTP JSON-контракт — шаблон в [`tools/online-plugin/`](../tools/online-plugin/README.md)).

---

## 1. Быстрый старт (на примере `https://app.bwa.ad/online.js`)

1. Откройте **Настройки → Онлайн**.
2. Нажмите **«+ Добавить плагин (Lampa / NX)»**.
3. Введите адрес плагина или сервера:
   ```text
   https://app.bwa.ad/online.js
   ```
   *(Также подходят адреса вида `http://192.168.1.10:9118`, `https://my-lampac.example.com/online/js/ВАШ_ТОКЕН`, `https://.../manifest.json`.)*
4. Если сервер требует токен — выберите **«Ввести токен»**, иначе нажмите **«Без токена»**.
5. Приложение само проверит соединение, определит тип плагина и покажет количество доступных балансеров (`VideoDB`, `VeoVeo`, `Kodik`, `AniLibria`, `Kinogo`, `Rezka`, `Filmix` и др.).
6. *(По желанию)* В том же разделе выберите:
   - **Источник по умолчанию:** `Торренты` или `Онлайн` (что открывает главная кнопка «Смотреть» и клик по серии).
   - **Предпочтительное качество:** `1080p`, `720p`, `480p`, `2160p` или `Авто`.

> [!NOTE]
> **Почему не работают скрипты вроде `https://nb557.github.io/plugins/online_mod.js`?**
> В Lampa есть два разных типа плагинов:
> - **Серверные (Lampac / BWA)** — имеют HTTP JSON-бэкенд (`/lite/events`, `/lite/...`), который делает парсинг и отдаёт чистые ссылки на потоки. Они работают в NX Torrent Player нативно.
> - **Браузерные DOM-скрипты (`online_mod.js` и аналоги на GitHub Pages)** — не имеют своего сервера, используют jQuery, `window.Lampa.*`, HTML-шаблоны и браузерный WebView для скрапинга прямо с устройства. В нативном C++/Borealis приложении без браузера такие скрипты запускать нельзя.

## 2. Как пользоваться онлайн-просмотром

### Фильмы
1. Откройте карточку фильма и нажмите **«Онлайн»** (или **«Смотреть»**, если в настройках выбран режим `Онлайн`).
2. Сверху выберите нужный **балансер** (`VideoDB`, `VeoVeo`, `Rezka` и т. д.).
3. В списке появятся доступные озвучки и версии с бейджами качества.
4. Нажмите **A** (или тап), чтобы начать просмотр в лучшем подходящем качестве, либо **X**, чтобы заранее выбрать конкретное разрешение (`1080p`/`720p`/`480p`).

### Сериалы и аниме
1. Откройте карточку сериала и выберите нужный сезон и серию (или нажмите **«Онлайн»** на карточке).
2. **При первом запуске сериала** откроется экран **«Онлайн»**, сразу нацеленный на выбранный сезон и серию. Выберите балансер и озвучку и нажмите **A**. Приложение **запомнит выбранный балансер и озвучку** для этого сериала.
3. **При выборе следующей серии или «Продолжить просмотр»:**
   - Внутри плеера доступен **список серий (`ZL`)**, кнопки **Пред. / След. серия** и карточка автоперехода в конце серии — следующая серия подтягивается автоматически в той же озвучке.
   - Если вы вышли в карточку сериала и позже нажали на другую серию (при режиме по умолчанию «Онлайн»), приложение автоматически запросит свежую ссылку для этой серии с запомненного балансера и озвучки.
   - Чтобы сменить балансер или озвучку, нажмите **«Онлайн»** на карточке сериала (или **X** на карточке серии).
4. **Внутри плеера (`X` / `+`):**
   - Доступно переключение **Качества** потока на лету (с сохранением текущей секунды просмотра).
   - Внешние **субтитры** от балансера отображаются в общем меню субтитров.
   - Прогресс просмотра сохраняется по `(tmdbId, сезон, серия)` в общую библиотеку; вместо временной CDN-ссылки (которая быстро истекает) сохраняется постоянный адрес источника `online://<плагин>/<балансер>?voice=...`, поэтому «Продолжить просмотр» работает даже спустя несколько дней.

## 3. Собственный сервер Lampac (опционально)

Если вы хотите максимальной стабильности, больше балансеров (`Rezka`, `Collaps`, `Alloha`, `Filmix`, `KinoPub` и др.) и конвертацию ID через `/externalids`, можно поднять свой **Lampac** в Docker на ПК, NAS или VPS:

1. Запустите Lampac (по умолчанию порт `9118`).
2. Добавьте в **Настройки → Онлайн** адрес `http://<IP_сервера>:9118` (и токен, если включён `accsdb`).

## 4. Как сделать свой плагин (`NX Online Plugin v1`)

Вы можете написать собственный плагин на любом языке (Node.js, Python, Go, PHP) или задеплоить бесплатно на Cloudflare Workers. Готовый шаблон лежит в [`tools/online-plugin/`](../tools/online-plugin/).

### Быстрый тест шаблона на ПК
```sh
cd tools/online-plugin
node server.mjs
```
Затем добавьте `http://<IP_ПК>:8787` в **Настройки → Онлайн** — появится плагин **NX Demo Online** с рабочими тестовыми HLS-потоками.

### Контракт HTTP JSON (`nx-online/v1`)

#### 1. `GET /manifest.json`
```json
{
  "schema": "nx-online/v1",
  "id": "my-online",
  "name": "My Online",
  "version": "1.0.0",
  "balancers": [
    { "id": "main", "name": "Main CDN" }
  ],
  "endpoints": {
    "streams": "/streams",
    "resolve": "/resolve"
  }
}
```

#### 2. `GET /streams`
Приложение передаёт query-параметры:
`balancer`, `tmdb_id`, `imdb_id`, `kp_id`, `type` (`movie` | `series`), `title`, `original_title`, `year`, `season`, `episode`, и опционально `token` (+ `Authorization: Bearer <token>`).

Ответ:
```json
{
  "type": "episodes",
  "voices": [
    { "name": "Дубляж", "url": "/streams?...&voice=dub", "active": true }
  ],
  "seasons": [
    { "number": 1, "name": "Сезон 1", "episodeCount": 10, "active": true }
  ],
  "items": [
    {
      "title": "Название серии",
      "season": 1,
      "episode": 1,
      "voice": "Дубляж",
      "method": "play",
      "url": "https://cdn.example.com/s1e1/master.m3u8",
      "qualities": {
        "1080p": "https://cdn.example.com/s1e1/1080.m3u8",
        "720p": "https://cdn.example.com/s1e1/720.m3u8"
      },
      "subtitles": [
        { "lang": "ru", "label": "Русские", "url": "https://cdn.example.com/s1e1/ru.vtt" }
      ],
      "headers": {
        "Referer": "https://player.example.com/",
        "User-Agent": "Mozilla/5.0"
      }
    }
  ]
}
```
Значения `method`:
- `"play"` — готовая ссылка (`mp4`, `mkv`, `m3u8`).
- `"call"` — отложенное получение ссылки (при выборе серии приложение вызовет `GET <url>` и ожидает JSON `{"url": "...", "qualities": {...}, "subtitles": [...], "headers": {...}}`).
- `"link"` — вложенный список (например, выбор сезона или уточнение совпадения).

## 5. Особенности на Nintendo Switch и диагностика

- На Switch FFmpeg из `portlibs` не содержит встроенных протоколов `https` и `crypto` (AES-128 HLS). Поэтому для онлайн-потоков приложение автоматически поднимает **локальный прокси `127.0.0.1`** (`hls_proxy`), который качает плейлисты `.m3u8` и сегменты через `libcurl` с `romfs:/cacert.pem`, пробрасывает `Referer`/`User-Agent` и при необходимости расшифровывает `AES-128-CBC` через `mbedTLS`. После закрытия плеера прокси останавливается и освобождает сокеты.
- На **Android и PC** потоки передаются напрямую в нативный `libmpv` (локальный прокси включается только если настроен SOCKS-прокси).
- **Если HTTPS-потоки не открываются на Switch** — проверьте системные **дату и время** на консоли (при сбитых часах не проходит проверка TLS-сертификатов).
- При необходимости включите **Настройки → О программе → Файл журнала** для просмотра подробных ошибок сети и `mpv`.

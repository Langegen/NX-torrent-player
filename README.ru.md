## 📖 Обзор

**NX Torrent Player** — это homebrew-видеоплеер для консоли Nintendo Switch с кастомной прошивкой (Atmosphère). В отличие от обычных загрузчиков, приложение не скачивает файл целиком перед воспроизведением: встроенный BitTorrent-клиент запрашивает и буферизирует фрагменты последовательно, благодаря чему видео начинает воспроизводиться буквально через несколько секунд после буферизации.

Приложение позволяет смотреть видео через каталоги и аддоны **Stremio**, искать раздачи по десяткам трекеров с помощью **Jackett**, а также воспроизводить локальные `.torrent` файлы и magnet-ссылки с карты памяти SD. Интерфейс построен на базе фреймворка `borealis` с родным для консоли управлением и поддержкой сенсорного экрана.

## ✨ Возможности

### 🌟 Нововведения в этом форке
- 🔍 **Поиск и стриминг через Jackett** — Поиск по всем настроенным трекерам Jackett прямо с консоли. Быстрые фильтры по категориям (*Все, Фильмы, Сериалы, Аниме*), сортировка (по сидам, размеру, дате), воспроизведение на лету или сохранение `.torrent` файлов на карту памяти.
- 🕒 **История просмотров и возобновление** — Вкладка **History** отслеживает просмотренные видео из всех источников (локальные, Jackett, Stremio). Запоминается прогресс и позиция, позволяя продолжить просмотр в один клик.
- 📂 **Умный выбор файлов и естественная сортировка** — Удобное окно выбора файлов для раздач с несколькими сериями/файлами. Сортировка учитывает числа в названиях (серии 1, 2, ..., 10 идут по порядку, а не 1, 10, 2).
- ⚡ **Улучшенный движок и опрос трекеров** — Фоновый пул потоков для одновременного анонса на более чем 30 трекерах, асинхронное получение метаданных для magnet-ссылок с возможностью отмены, а также фолбэк на DHT для бестрекерных раздач.
- 🧪 **Тестовый набор для ПК** — Автономный тестовый набор (`pctest/`) с встроенной поддержкой SHA-1 для проверки и отладки торрент-движка на компьютере без необходимости сборки под Switch.

### 🎬 Базовые возможности
- **Последовательный стриминг** — Быстрый запуск воспроизведения; движок скачивает куски с опережением и мгновенно перестраивается при перемотке.
- **Интеграция со Stremio** — Вход в учетную запись Stremio, доступ к библиотеке, постерам, метаданным Cinemeta, установленным дополнениям и источникам.
- **Локальные торренты и магниты** — Поддержка `.torrent` файлов в папке `/switch/NX-torrent-player/torrents/` и magnet-ссылок (через `magnet.txt` или ввод с экранной клавиатуры).
- **Продвинутый плеер на mpv** — Аппаратное ускорение, переключение дорожек аудио и субтитров (включая внешние субтитры из аддонов Stremio), плавная аналоговая перемотка стиками, изменение скорости, усиление звука в портативном режиме.
- **Интерфейс в стиле Horizon** — Родной внешний вид системы Nintendo Switch, полноценная поддержка кнопок контроллера и тачскрина.

## 📥 Установка

### Требования
- Консоль Nintendo Switch с установленной кастомной прошивкой (**Atmosphère**).
- Свободное место на карте microSD для кэширования буфера видео.
- Подключение к интернету (Wi-Fi или LAN) с корректно выставленными датой и временем на консоли.

### Инструкция
1. Загрузите свежую версию `NX-torrent-player.nro` со страницы [**Releases**](https://github.com/Langegen/NX-torrent-player/releases).
2. Скопируйте файл на microSD-карту по пути:
   ```text
   sdmc:/switch/NX-torrent-player/NX-torrent-player.nro
   ```
3. Вставьте карту в Switch и откройте **Homebrew Menu**.
4. **Важно**: Запускайте Homebrew Menu в режиме **Title Override** (зажмите клавишу **R** при запуске любой установленной игры), чтобы приложению был выделен весь объем оперативной памяти. Запуск в режиме апплета (через Альбом) жестко ограничен по памяти и намеренно заблокирован, чтобы избежать сбоев при воспроизведении видео.

> [!TIP]
> **Автообновление**: Проверять и скачивать обновления можно прямо в приложении (**Options → Check on startup**). При выходе свежей версии плеер сам загрузит её и обновит файл `.nro`.

## 🎮 Управление

| Кнопка / Ввод | Где действует | Действие |
| :--- | :--- | :--- |
| **A** | Меню / Списки | Выбор / Воспроизведение |
| **B** | Меню / Окна | Назад / Отмена / Закрыть диалог |
| **X** | Stremio | Добавить/удалить из библиотеки / Скрыть плитку «Продолжить просмотр» |
| **Y** | Local / History | Удалить `.torrent` / удалить пункт из истории |
| **Y** | Jackett | Сохранить `.torrent` или магнит в локальную библиотеку |
| **Y** | Плеер | Блокировка управления (защита от случайных нажатий) |
| **L / R** | Браузер | Переключение видов / фильтров в Stremio |
| **L / R** | Плеер | Регулировка скорости воспроизведения (или задержки субтитров) |
| **Левый / Правый стик** | Плеер | Плавная аналоговая перемотка видео вперед / назад |
| **Сенсорный экран** | Везде | Выбор касанием, прокрутка жестами, экранные кнопки плеера |
| **ZR** | Плеер | Панель реального времени со статистикой движка и сети |

## 🧭 Руководство пользователя

### 1. 🕒 История просмотров (History)
Вкладка **History** фиксирует все открытые видеофайлы:
- Отображаются название, источник, просмотренная длительность и полоса прогресса.
- Нажатие кнопки **A** на элементе автоматически возобновляет просмотр с места остановки (действует для видео, просмотренных дольше 15 секунд и не завершенных до 95%).
- Кнопка **Y** удаляет выбранный пункт из истории. Также доступна кнопка полной очистки истории.

### 2. 🔍 Поиск через Jackett
Во вкладке **Jackett** (или в меню **Options → Jackett**) укажите параметры подключения:
- **Server URL**: Адрес вашего сервера Jackett (например, `http://192.168.1.100:9117`).
- **API Key**: API-ключ Jackett (необязателен; если в Jackett авторизация отключена, поле можно оставить пустым).
- **Возможности**:
  - Быстрый поиск по всем активным трекерам с фильтрацией: **Все**, **Фильмы**, **Сериалы**, **Аниме**.
  - Сортировка выдачи: по числу раздающих (сидов), по размеру файла, по дате добавления.
  - Нажатие **A** запускает воспроизведение (для раздач с несколькими файлами открывается список выбора серии).
  - Нажатие **Y** сохраняет `.torrent` файл в локальную библиотеку (`/switch/NX-torrent-player/torrents/`).

### 3. 📺 Просмотр через Stremio
Во вкладке **Stremio** введите логин (e-mail) и пароль вашей учетной записи:
- Сессия сохраняется между запусками (выйти из аккаунта можно в настройках Options).
- Доступны разделы библиотеки, рекомендации, сезоны и серии.
- Воспроизводятся раздачи от установленных в профиле BitTorrent-аддонов (например, Torrentio).
- **Фильтр 4K**: По умолчанию потоки в разрешении 4K скрыты, так как Switch в доке выводит сигнал максимум 1080p. При необходимости отображение 4K можно включить в настройках.

### 4. 📁 Локальные торренты и Magnet-ссылки
- Поместите файлы `.torrent` в директорию `sdmc:/switch/NX-torrent-player/torrents/` (подпапки также сканируются).
- Magnet-ссылки можно добавить, отредактировав файл `sdmc:/switch/NX-torrent-player/torrents/magnet.txt` (по одной ссылке или инфо-хэшу на строку), либо нажав кнопку **Add magnet** во вкладке Local (с вводом через экранную клавиатуру).
- Метаданные магнита определяются в фоне и кэшируются для быстрого повторного открытия.
- Нажатие **Y** позволяет удалить `.torrent` файл с карты памяти или убрать магнет-ссылку.

## 🛠️ Сборка из исходников

### Сборка под Nintendo Switch (.nro)
Сборка выполняется внутри официального Docker-образа devkitPro, поэтому локально устанавливать devkitA64 не требуется:

```sh
# 1. Создаем том для кэша сборки и конфигурируем (один раз)
docker run --rm -v st_build:/build -v "$PWD":/project -w /build \
    devkitpro/devkita64:latest sh -c "cmake /project"

# 2. Компилируем NX-torrent-player.nro
docker run --rm -v st_build:/build -v "$PWD":/project -w /build \
    devkitpro/devkita64:latest \
    sh -c "cmake --build . --target NX-torrent-player.nro"

# 3. Копируем скомпилированный файл .nro в текущую папку
docker run --rm -v st_build:/build -v "$PWD":/project \
    devkitpro/devkita64:latest sh -c "cp /build/NX-torrent-player.nro /project/"
```

> [!NOTE]
> В среде Windows (Git Bash или MSYS2) добавляйте перед командами `MSYS_NO_PATHCONV=1`, чтобы избежать искажения путей к каталогам.

### Сборка тестов для ПК
Скомпилировать автономный тест движка можно в Linux/macOS или WSL:
```sh
cd pctest
./build.sh
./enginetest
```
